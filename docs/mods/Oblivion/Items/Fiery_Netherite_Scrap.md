## Description
The fiery netherite scrap is a somewhat rare ingot material. It can be smelted from a [raw fiery netherite](/wiki/mods/Oblivion/Items/Raw_Fiery_Netherite) and is used to craft [fiery netherite ingot](/wiki/mods/Oblivion/Items/Fiery_Netherite_Ingot).

## Obtaining
<div id="crafting-table">
<div class="crafting-element" crafting-type="blast_furnace_smelting">
input[
    1=oblivion:raw_fiery_netherite, Raw Fiery Netherite, Oblivion/Items/Raw_Fiery_Netherite, true
]
output[oblivion:fiery_netherite_scrap, Fiery Netherite Scrap]
</div>
</div>
