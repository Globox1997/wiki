## Description
Cooked shlamb is a [food](https://minecraft.wiki/w/Food) [item](https://minecraft.wiki/w/Item) that can be eaten by the [player](https://minecraft.wiki/w/Player).

## Obtaining
#### Cooking
<div id="crafting-table">
<div class="crafting-element" crafting-type="furnace_smelting">
    input[ 1=oblivion:shlamb, shlamb, oblivion/Items/Shlamb, true ]
    output[oblivion:cooked_shlamb, Cooked shlamb]
</div>
</div>

## Usage
To eat cooked shlamb, press and hold use while it is selected in the hotbar. Eating one restores <span class="icon-element" icon-count="7" icon-id="hunger"></span> hunger and <span class="icon-element" icon-count="22.4" icon-id="saturation"></span> [saturation](https://minecraft.wiki/w/Hunger#Mechanics).
