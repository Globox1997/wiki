## Description
Cooked turkey is a [food](https://minecraft.wiki/w/Food) [item](https://minecraft.wiki/w/Item) that can be eaten by the [player](https://minecraft.wiki/w/Player).

## Obtaining
#### Cooking
<div id="crafting-table">
<div class="crafting-element" crafting-type="furnace_smelting">
    input[ 1=oblivion:turkey, Turkey, oblivion/Items/Turkey, true ]
    output[oblivion:cooked_turkey, Cooked Turkey]
</div>
</div>

## Usage
To eat cooked turkey, press and hold use while it is selected in the hotbar. Eating one restores <span class="icon-element" icon-count="7" icon-id="hunger"></span> hunger and <span class="icon-element" icon-count="16.8" icon-id="saturation"></span> [saturation](https://minecraft.wiki/w/Hunger#Mechanics).
