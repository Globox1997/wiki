## Description
A fiery netherite helmet is an end game [armor](https://minecraft.wiki/w/Armor) piece that provides [players](https://minecraft.wiki/w/Player) and certain [mobs](https://minecraft.wiki/w/Mob) protection from common [damage types](https://minecraft.wiki/w/Damage_type) and appear graphically on the wearer.

## Obtaining
#### Crafting
<div id="crafting-table">
<div class="crafting-element" crafting-type="smithing">
input[
    1=oblivion:fiery_netherite_upgrade_smithing_template,Fiery Netherite Upgrade Smithing Template, Oblivion/Items/Fiery_Netherite_Upgrade_Smithing_Template, true; 
    2=netherite_helmet,Netherite Helmet, https://minecraft.wiki/w/Netherite_Helmet; 
    3=oblivion:fiery_netherite_ingot, Fiery Netherite Ingot, Oblivion/Items/Fiery_Netherite_Ingot, true
]
output[oblivion:fiery_netherite_helmet, Fiery Netherite Helmet ]
</div>
</div>

## Usage
A fiery netherite helmet can be worn in the head slot of the [inventory](https://minecraft.wiki/w/Inventory) to give <span class="icon-element" icon-count="3" icon-id="armor"></span> [protection](https://minecraft.wiki/w/Armor#Protection), <span class="icon-element" icon-count="3.5" icon-id="armor"></span> [armor toughness](https://minecraft.wiki/w/Armor#Armor_toughness) and 1.5 (15%) [knockback resistance](https://minecraft.wiki/w/Knockback_(mechanic)#Knockback_resistance).
