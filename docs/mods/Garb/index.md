# Description
Before you enter the world, choose a class to get certain perks which enhances the chosen playstyle from the beginning! Three different characters can get created with the chosen player name and skin!

---
## Content
This mod does not add blocks, items nor entities.  

## Datapack
Classes can get added/changed, for more info checkout the [github readme](https://github.com/Globox1997/Garb)
